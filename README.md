# Internet Speed Test

Консольная утилита на Node.js для измерения скорости загрузки данных с указанного URL.

По умолчанию программа выполняет 10 последовательных запросов к тестовому endpoint Cloudflare, полностью считывает тело каждого ответа и выводит сводную статистику.

## Возможности

- 10 последовательных HTTP-запросов.
- Ожидание полной загрузки тела каждого ответа.
- Среднее время одного запроса.
- Общий объём загруженных данных.
- Итоговая скорость загрузки в Мбит/с.
- Проверка URL, обработка HTTP-ошибок и тайм-аутов.
- Возможность указать собственный URL.

## Требования

- Node.js **24.20.0 или новее**.
- npm, который устанавливается вместе с Node.js.

Сторонние npm-зависимости не используются. Применяются встроенные возможности Node.js: `fetch`, `URL`, `AbortSignal.timeout` и `node:perf_hooks`.

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/<your-username>/internet-speed-test.git
cd internet-speed-test
```

Запустите тест одной командой:

```bash
npm start
```

По умолчанию используется тестовый адрес:

```text
https://speed.cloudflare.com/__down?bytes=1000000
```

Чтобы проверить другой URL, передайте его после `--`:

```bash
npm start -- "https://your-domain.com/test-file.bin"
```

Также доступна команда:

```bash
npm test
```

## Единицы измерения и методика

Скорость выводится в **Мбит/с (Mbps)**, где 1 Мбит = 1 000 000 бит.

Формула:

```text
Скорость (Мбит/с) =
  общий объём данных (байт) × 8
  / общее время теста (секунды)
  / 1 000 000
```

- **Среднее время запроса** — сумма времени выполнения всех запросов, делённая на количество запросов.
- **Общий объём данных** — сумма размеров тел всех успешно загруженных HTTP-ответов.
- **Общее время теста** — время от начала первого запроса до полного получения последнего ответа.
- **Суммарное время запросов** — сумма индивидуальных длительностей запросов.

Размер тела определяется через `ArrayBuffer.byteLength`. Это объём тела ответа после обработки HTTP-сжатия средствами `fetch`, а не обязательно точное число байтов, переданных по сети на транспортном уровне.

Запросы выполняются последовательно: следующий начинается только после полного завершения предыдущего.

## Обработка ошибок

- Некорректный URL и неподдерживаемая схема приводят к сообщению об ошибке.
- Для каждого запроса установлен тайм-аут 30 секунд.
- При HTTP-ошибке или сетевой ошибке тест прекращается.
- При ошибке процесс завершается с ненулевым кодом.

## Ограничения

Результат показывает скорость загрузки с выбранного сервера в текущих сетевых условиях. На него могут влиять производительность и расположение сервера, кэширование, ограничения частоты запросов и другие факторы. Это не универсальное измерение максимальной пропускной способности интернет-канала.
